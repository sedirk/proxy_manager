# 本地场景材料

此目录在开发电脑中保存原始对话、交接压缩包，以及 WoWS 和 UU 共存的现场记录。它们可能包含本机网络信息，因此保留在本地，不随 Git 仓库上传。

项目依据这些场景实现：

- Steam 社区与游戏下载分别分流。
- 分清系统 hosts、应用 DNS、代理核心 DNS 和 TUN 的作用范围。
- WoWS 更新下载与 Codex 当前连接同时保持可用。
- 将 UU 加速器与普通 HTTP / SOCKS 代理分别检测。
- 将 TCP 探测、完整下载和 RustDesk 会话的验证结果分别展示。

可公开复用的操作与验收步骤见 `docs/使用指南.md` 和 `docs/验收指南.md`。
