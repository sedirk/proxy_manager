# 0.4.0 · 在路由图中直接设置应用连接

主界面回到路由设计画布。左侧选择本机软件，右侧自动列出识别到的代理入口，软件到入口的连线对应同一项可保存、可启动的应用连接设置。

- 连线或在属性中选择“连接到”，然后点“保存连接设置”。图中区分“待保存”与“设置已保存”。
- 关闭目标软件后，在同一属性面板点“按此设置启动”，新进程采用保存配置；不需要先完成问诊或导出脚本。
- 支持沿用默认设置、清除新进程代理环境，以及连接到识别到的本机 HTTP 入口。Chrome/Edge 另使用显式代理参数，其他软件仍需支持环境变量。
- 连接设置按程序路径独立保存到当前数据目录的 `.local/app-routes.json`，与原高级中继方案分开。重启保留，重新连线后需再保存；不会因编辑一条应用连接而改动其他中继规则。
- 属性内可直接检测当前线路与目标地址。已保存、最近启动和实际网络结果分别表示，不把画线包装成透明强制接管。
- 保留 v2rayN/核心归属、UU、aTrust、ZeroTier 的自动识别；加速/隧道专用端口不会作为应用代理入口。复杂域名分流通过“高级中继规则”进入。

0.3.0 的问诊式首页未发布。本版采用可视化配置作为默认操作路径。
