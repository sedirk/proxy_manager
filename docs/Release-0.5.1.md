# FlowDesk 0.5.1 · 网络工具拖入与代理入口检测

0.5.0 左下角的网络工具卡片只能查看详情，无法拖入画布。发现 v2rayN / Xray 监听但没有协议来源时，也不会生成 HTTP 出口，界面缺少继续处理的入口。本版修复这些操作，并补全 v2rayN 外置数据目录的识别。

- 所有已识别网络工具支持点击、键盘和拖入；HTTP 目标按地址复用并定位到视野内，不重复创建或自动连线。
- 协议未确认的代理显示观察卡片和“检测代理入口”；没有监听时提示先启动代理并重新检测。UU、aTrust、ZeroTier 保留加速/组网说明，不能接作 HTTP 出口。
- 检测仅选择已观察且归属明确的应用代理 TCP 环回监听，通过 HTTP CONNECT 转发至临时本机挑战服务。只有该服务实际收到本次请求并返回正确响应，才生成 HTTP 入口；单纯监听、HTTP 200 或回显不算通过。
- 检测前后重新核对监听归属，设总截止时间，失败复查撤销旧确认。确认仅保存在当前 FlowDesk 进程中，监听身份变化后不再使用；不访问外网、不改系统代理/TUN、不启动用户应用、不保存应用连线。
- v2rayN GUI 与数据目录分离时，按已观察核心父关系和受限目录布局查找生成配置，保留协议来源和未验证加载状态的区别，不新增 GUI 配置或订阅扫描。

升级：旧页面右上角“退出后台” → 运行新版 EXE → 刷新页面。点击左下角 v2rayN → “检测代理入口”（若尚无 HTTP）→ 连接应用并保存。UU 和 ZeroTier 可以拖到画布查看，其卡片不提供 HTTP 接线端口。

验证使用真实本机中继及异常响应样例、API 授权和身份变化测试、界面拖放事件固定样例与打包 EXE。没有远程操作用户的新电脑；其实际代理规则与网站访问仍需在新版中检查。浏览器视觉验收未完成。

222 项 Python 测试、35 项应用画布检查、8 项高级分流检查及 11 项手动软件清单检查通过。中文/空格路径 EXE 验收通过；本机升级后实际 API 已确认一个 Xray HTTP CONNECT 入口，保存方案/软件清单/应用连接文件、WinINet、WinHTTP、持久代理环境及受保护进程均保持不变。
