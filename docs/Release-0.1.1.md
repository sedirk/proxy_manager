# v0.1.1 · Windows 免 Python 单文件版

下载 `FlowDesk-0.1.1-windows-x64.exe`，双击运行。程序会打开本机浏览器界面，无需安装 Python，无需管理员权限。

## 本次变化

- 内置 Python 与界面资源，提供 Windows x64 单文件程序。
- exe 用户数据保存在 `%LOCALAPPDATA%\FlowDesk\.local`，替换新版程序后继续保留。
- 修正冻结程序的独立回退守护启动方式，并为单文件解压预留启动时间。
- 源码版继续使用项目 `.local`；两版间可通过界面导出、导入方案。

## 验证

- 107 项自动化测试通过。
- 实际 exe 在带中文和空格的目录、不含 Python 的子进程 PATH 下运行通过。
- 界面资源、重复打开复用实例、方案保存后重启恢复、只读 Windows 检测、真实回环 HTTP 中继、守护内部入口、正常退出均通过。
- 测试期间真实系统代理配置前后相同，未接管系统代理。回退写入逻辑由替身适配器测试覆盖。

本次未使用全新 Windows 虚拟机验证；exe 已内置运行时，但验收环境本身仍安装有 Python。程序未使用商业代码签名证书。

## 文件

- `.exe`：主程序，约 10 MB。
- `SHA256SUMS.txt`：下载完整性校验值。
- `THIRD_PARTY_NOTICES.txt`：内置运行时的许可说明（同时嵌入 exe）。

退出使用页面右上角“退出后台”；只关闭网页会保留后台。启动程序只做检测，不会自动修改 v2rayN、UU、TUN 或系统代理。
