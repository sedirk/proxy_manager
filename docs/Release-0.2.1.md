# 0.2.1 · 手动添加本机软件

自动检测之外，现在可以在“本机软件”标题旁点击“添加软件”，浏览选择 Windows 可执行文件或粘贴完整路径，并设置显示名称。

- 手动清单保存在当前数据目录，刷新检测、关闭页面或重启工作台后仍会保留。
- 同一程序路径与自动发现的条目合并；程序文件迁移或消失时保留登记并提示路径失效。
- 应用详情支持移除手动登记，不卸载软件、不删除文件、不停止进程。
- 添加、选择和移除操作都不会启动目标程序或修改系统代理；Codex、代理核心等保护规则仍然适用。
- 本次一并发布 0.2.0 的应用与设置工作区、日志定位与有界脱敏读取、连接证据、新进程环境脚本和项目数据目录统一支持。

构建先生成候选文件，完整性检查与独立 EXE 验收通过后才替换正式文件。无需在使用者的电脑上安装 Python。

手动添加只登记软件；是否采用某一代理、是否绕过 TUN，以及 UDP/QUIC 和最终出口仍需实际验证。

## 验收

165 项 Python 测试、11 项前端事件回归与实际浏览器中的 6 项添加清单操作检查通过。独立 EXE 在中文和空格目录通过启动、重复打开、添加去重、重启与检测后保留登记、移除不删除文件、本地中继请求和退出检查。测试没有修改系统代理。

原生文件选择器已检查 PowerShell 语法与 API 隔离行为；浏览器端到端验收使用粘贴路径，没有自动操作 Windows 文件选择窗口。
