# 0.1.0 验收结果

日期：2026-10-24。环境：Windows 开发测试环境。以下记录对应 0.1.0 的实际观察与测试；后续版本以各自发布说明为准，不代表所有软件和网络环境都已验证。具体机器配置仅在本地验收记录中保留。

## 自动化测试

`python -X utf8 -m unittest discover -s tests -v`：100 项全部通过，耗时 17.491 秒。覆盖发现与分类、规则校验、HTTP / CONNECT / SOCKS5 TCP 中继、探测、脱敏、系统代理接入与恢复、服务生命周期和控制 API。系统代理写入测试使用替身适配器，没有对真实 WinINet 执行接管。

完整输出保留在项目的 `artifacts/test-results.txt`。前端 JavaScript 语法检查通过。

## 界面与本地网络验收

隔离测试实例使用临时数据目录、回环 HTTP 源站，并禁止真实系统代理接入。通过浏览器完成了预览、启动多个入口、域名映射与规则分流探测、查看活动记录、修改草稿、停止入口和刷新恢复草稿。探测经过实际中继获得 HTTP 200；连接建立和完成事件使用同一个连接 ID。

修改草稿不会改变正在运行的方案。停止后中继已退出，测试实例已关闭。验收确认原有方案与页面草稿保留，非测试实例未启用中继或系统接入。

界面预览：`artifacts/flowdesk-preview.png`。回环验收记录：`artifacts/loopback-verification.json`。

## UU 共存观察

测试环境中检测到加速器进程及相关监听，按加速层与私有监听分类，不作为已经验证的 HTTP / SOCKS 出口。软件界面的加速与 hosts 相关开关通过人工核对记录；自动检测没有读取这些私有开关，人工界面记录不能作为持续自动确认的事实。

两次快照之间观察到 hosts 有效映射发生变化，未确定写入者。没有观察到与加速器私有监听地址对应的 hosts 回环映射，不据此推断其具体重定向机制。

前后 WinINet 配置指纹相同。验收保留代理客户端、核心、加速器及工作连接的既有进程，没有停止这些进程，也没有切换 TUN、系统代理、路由或 hosts。

完整观察记录仅在被 Git 忽略的 `artifacts/` 中保留。原始场景资料也仅在本地保留，不随源码发布；公开文档保留验证方法与结论，不包含机器清单和网络快照。

## 已知范围

没有在真实游戏、更新下载或 RustDesk 远程会话中验证端到端网络路径。接线图驱动显式接入的本地 TCP 中继，不是任意进程的强制代理器；UU 驱动、WFP、UDP 与 QUIC 不在本版接管范围。直连仍遵循系统路由，存在 TUN 时不能仅凭“直连”标签断言绕过 TUN。

高级系统接入的超时恢复、守护与第三方冲突处理已用替身验证；真实机器保持未接管。冲突时保留第三方设置并显示处理状态，不承诺任何故障下都能无条件恢复。

源码包不含 `.local` 私人状态、原始交接压缩包或机器诊断记录。解压后需要 Python 3.11 或更新版本，按 README 启动。
