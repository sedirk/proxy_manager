# 0.1.0 验收结果

日期：2026-10-24。环境：Windows、本机 Python 3.13。以下为本次实际观察与测试，不代表所有软件和网络环境都已验证。

## 自动化测试

`python -X utf8 -m unittest discover -s tests -v`：100 项全部通过，耗时 17.491 秒。覆盖发现与分类、规则校验、HTTP / CONNECT / SOCKS5 TCP 中继、探测、脱敏、系统代理接入与恢复、服务生命周期和控制 API。系统代理写入测试使用替身适配器，没有对真实 WinINet 执行接管。

完整输出保留在项目的 `artifacts/test-results.txt`。前端 JavaScript 语法检查通过。

## 界面与本地网络验收

隔离测试实例使用临时数据目录、回环 HTTP 源站，并禁止真实系统代理接入。通过浏览器完成了预览、启动六个入口、域名映射与规则分流探测、查看活动记录、修改草稿、停止入口和刷新恢复草稿。探测经过实际中继获得 HTTP 200；连接建立和完成事件使用同一个连接 ID。

修改草稿不会改变正在运行的方案。停止后中继已退出。测试实例已关闭。正式实例保留原有方案与用户页面草稿，正式中继未启动、系统接入状态为 detached。

界面预览：`artifacts/flowdesk-preview.png`。回环验收记录：`artifacts/loopback-verification.json`。

## UU 共存观察

检测到网易 UU 的三个进程及 35 个关联监听口。它们归类为加速器及私有监听，不作为已经验证的 HTTP / SOCKS 出口。用户截图显示 WoWS 国际服加速中，“加速时禁用网络代理”关闭，“解决本地 Hosts 文件域名冲突”开启；自动检测没有读取这些开关，不把截图状态当成可持续自动确认的事实。

两次快照之间 hosts 的有效映射数从 239 变为 244；未确定写入者。没有观察到与 UU 私有监听地址对应的 hosts 回环映射，不据此推断 UU 的具体重定向机制。

系统代理仍为 `127.0.0.1:10808`，前后 WinINet 配置指纹相同。v2rayN、Xray、UU 与 Codex 进程仍运行。本次没有停止它们，没有切换 TUN、系统代理、路由或 hosts。

观察记录：`artifacts/uu-readonly-verification.json`、`artifacts/network-preservation.json`。WoWS 和 UU 场景已加入 `question_example`，原始材料保留。

## 已知范围

没有在真实游戏、更新下载或 RustDesk 远程会话中验证端到端网络路径。接线图驱动显式接入的本地 TCP 中继，不是任意进程的强制代理器；UU 驱动、WFP、UDP 与 QUIC 不在本版接管范围。直连仍遵循系统路由，存在 TUN 时不能仅凭“直连”标签断言绕过 TUN。

高级系统接入的超时恢复、守护与第三方冲突处理已用替身验证；真实机器保持未接管。冲突时保留第三方设置并显示处理状态，不承诺任何故障下都能无条件恢复。

源码包不含 `.local` 私人状态、原始交接压缩包或机器诊断记录。解压后需要 Python 3.11 或更新版本，按 README 启动。
