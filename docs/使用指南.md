# 流向使用指南

## 从一个软件开始

默认进入 **解决连接问题**，先选软件、粘贴报错或填写失败地址，再点 **检测并给出建议**。例如安装器下载失败，可以直接粘贴包含 `https://…` 的报错，页面会提取待检测地址。

首页识别 v2rayN 与其 Xray 等核心的父子进程关系，列出有配置或系统代理依据的本地入口；同时展示 UU、aTrust 和 ZeroTier 的运行、服务与网卡线索。点击“识别依据”可以核对端口所属进程。加速器、企业隧道、虚拟组网的专用端口不会作为 HTTP/SOCKS 代理供应用选择。

检测会比较普通连接和最多三个明确的代理入口。若普通连接失败而 HTTP 代理可达，页面会说明理由，并提供 **准备此软件的代理启动方案**。核对软件名称与入口，关闭目标软件，再点 **按方案启动**；目标仍在运行时会提示关闭，工作台不会结束它。随后在原软件里重试下载、登录等操作，再在引导页选择 **已经成功** 或 **仍然失败**。反馈记录是用户确认；检测成功本身不能替代真实操作。

HTTP 401/403/404/405/429 会提示核对地址、权限或检测方式；所有路径均失败时提示先检查代理节点或企业网络；只有 SOCKS 路径可达时，会说明需要应用支持或启用 HTTP 入站。流程不会把每个问题都归结为“打开系统代理”。

需要进一步查看证据时，切到 **应用与设置**，搜索软件，按右侧 **设置来源 → 启动配置 → 日志与配置 → 连接证据** 查看。

没有找到软件时，在 **本机软件** 标题旁点 **添加软件**。用 **浏览…** 选择 `.exe`，或粘贴完整路径，可选填显示名称，再点 **添加到清单**。添加不运行程序、不改代理；清单保存在本机，刷新和重启后仍会保留。同一路径不会重复添加。浏览窗口取消时不会产生登记；窗口无法打开时可直接粘贴路径。

在手动添加的软件详情中可 **移除手动登记**；这不会卸载软件、删除文件或关闭进程。若同一软件也被自动检测到，移除手动登记后自动发现条目仍会显示。文件已移动或删除时，清单会保留并提示路径失效，可移除后按新路径添加。

- 设置来源分别解释系统代理/PAC、WinHTTP、用户与机器环境变量、应用自身设置、TUN/路由。界面会标明观察时间和旧快照；它没有读取其他进程的完整环境。
- 日志位置区分“已发现”和“候选”。已发现资源可打开所在目录，独立的文本日志可查看脱敏尾部；配置文件只定位，不把订阅、令牌等配置内容当日志读取。发生日志轮转时重新检测再选择。
- 启动配置只生成可审查的 PowerShell 文件。直接运行脚本仅显示说明；检查后使用 `-Launch` 才会创建新进程。既有实例不被停止，后台辅助进程也不会被当成主程序启动。
- “清除新进程代理环境”只清理该子进程的代理变量，并不代表它不再使用系统代理、私有配置或 TUN。指定 HTTP/SOCKS 环境也需该软件支持；受保护应用没有此入口。
- 连接证据可说明观察到的 TCP 下一跳，不能仅凭本地代理端口或目标 IP 判断最终节点、真实下载或 UDP/QUIC 是否走代理。

需要编辑分流方案时切到 **路由设计**；两个视图共享同一份工作台，切换不会重置未保存草稿。

## 先看这四种状态

| 状态 | 能说明什么 |
| --- | --- |
| 设计方案 | 你希望通道走向哪个出口，尚未控制真实应用 |
| 本机已观察 | 检测时读到了哪些设置、进程、端口、接口或变化 |
| 中继端口已监听 | 本工具的环回入口运行中，可接收显式发送到这里的请求 |
| 真实应用未验证 | 当前没有足够证据确认真实下载、远程会话或持续连接 |

代理端口存在、进程运行或配置声明了协议，都不等于出口可用。检测界面保留“观察”“未知”“待验证”，探测成功不会将任意应用标记为正常。

## 检测并理解当前机器

启动后点击 **自动检测**。底部 **分层证据** 展示 WinINet、WinHTTP、工作台进程环境、用户/机器环境、代理配置线索、接口和 hosts / DNS。工作台进程的环境变量不代表 Codex 或其他进程的实际环境。

代理候选库只显示识别出的代理线索；所有 TCP / UDP 监听另计总数，常见端口号不会被直接当成协议证明。**本机变化** 会列出前后值，写入者未知时仍显示未知。

UU 运行时会出现独立的加速层和上下文节点，可见进程、监听数、hosts 线索与共存发现。工作台无法读取的 UU 选项仍需你在 UU 界面核对；检测到 hosts 变化也不据此推断写入者。

## 接一个应用通道

先切换到 **路由设计**。

1. 从左侧应用库选择应用。Steam、WoWS 和 RustDesk 有初始模板；Codex、UU、hosts / DNS 是上下文或保护节点。
2. 点击应用通道右侧圆点，再点击出口左侧圆点。虚线代表设计连接。
3. 在右侧编辑通道名称、默认出口和域名规则。规则从上到下首次匹配，未命中时使用默认出口。规则可填精确域名、IP、`*.example.com` 或 `*`；`*.example.com` 不包含根域名 `example.com`。
4. **本地入口端口** 填 `0` 由系统分配；需要应用长期保留同一个代理地址时可指定空闲固定端口。启动返回的端口才是实际值。
5. **保存方案** 只保存设计。点击 **预览影响** 阅读问题、限制和映射数量，再点击 **只启动本地入口**。

启动后，底部 **运行入口** 与通道属性可复制实际 `http://127.0.0.1:端口` 代理 URL。只有应用明确采用这个入口，请求才会经过本中继。若应用没有代理配置或忽略系统代理，画线本身不能控制它。

运行中修改草稿，不会悄悄更改已有连接或运行规则。完成编辑后停止入口，重新预览、启动。停止会中断经过本入口的连接。

默认画布聚焦当前通道与相关出口，以至少 70% 缩放显示，必要时可上下平移。点击 **全部节点** 或按 `0` 才进入整体总览；**聚焦通道** 返回可读的当前通道视图。窗口宽度不超过 1000 像素时，应用库变成图标栏，属性改为可开关抽屉，画布上方可展开应用库、打开属性。空格拖动画布，Ctrl + 滚轮缩放；选中节点后可用 Alt + 方向键移动。手动缩放后，轮询和窗口调整不会自动缩回总览。

## 用探测确认实际路径

**出口属性 → 有界连通探测** 使用当前草稿中的出口，适合核对一个 HTTP / SOCKS5 上游是否可达，不代表应用已经接入。

**通道属性 → 验证运行中的通道** 使用已经启动的实际入口、规则和解析映射。这里采用运行配置，未应用草稿不会影响结果。输入一个你准备访问的 HTTP(S) URL，或选择 WebSocket 升级握手后输入相应 URL，再探测。

结果逐层显示 DNS / TCP / TLS / HTTP / WebSocket 等证据。活动中的 **路径已建立 / 进行中** 只证明当前 TCP 路径已建立；连接结束、字节数和真实应用表现要继续观察。HTTPS 隧道不会被解密。

## 常用场景

**Steam 社区走代理、下载走直连：** 使用现有代理作为默认出口，为已确认的下载域名添加直连规则。模板中的域名是起点，不能覆盖全部 CDN。实际请求经过本入口后，活动记录会显示域名、通道和命中出口；点击 **添加直连规则** 只加入草稿，核对后重新启动配置。若没有 Steam 事件，先核对 Steam 是否真的采用了本入口。

**WoWS 三端更新直连：** 三个通道分别配置。先在游戏资源切换器里完成更新隔离，再自行打开官方客户端；这里既不启动下载，也不更改游戏文件。仍须验证客户端是否采用入口、实际出口与下载流量。

**RustDesk 与 TUN 共存：** TCP 直连、绑定接口、代理 CONNECT 和真实 RustDesk 会话是不同证据。DIRECT 仍可能进入默认 TUN 路由，本工具不自动改排除路由或验证 UDP 打洞。能访问一个测试端口，不足以证明远程会话可用。

**hosts 在代理下看似失效：** 选择 hosts / DNS 节点，比较系统解析与匹配的 hosts 线索。上游代理可能独立解析域名。需要固定本中继的目标地址时，添加“精确域名 → 字面 IP”映射，随后预览并重新启动。映射不接受 URL 或通配符，不修改系统 hosts，并保留原 HTTP Host / TLS 域名。

## 可回退的系统接入

只有明确需要让采用 WinINet 的应用一起使用某个运行入口时，才展开右侧 **高级 · 系统接入**：

1. 选择已运行通道，点击 **预览系统接入**。
2. 阅读原设置、新设置、后端允许条件、域名规则和 DNS 映射。它们影响所有采用这个系统入口的应用，无法按进程区分；Codex 保护节点也不能阻止依赖系统代理的新连接受到此项显式变更影响。
3. 后端允许后勾选范围确认，再点击 **应用并观察，未确认会回退**。
4. 在 60 秒内实际检查连接。连接正常可点 **连接正常，确认保留**；也可立即 **恢复原系统代理**。未确认、停止或正常退出会请求恢复本工具的设置。

如果其他软件在此期间改了系统代理，界面会提示冲突或恢复失败，保留备份和入口以供处理。不要靠连续点击或直接杀后台解决冲突；先核对当前系统代理及提示。回退保护不是强行覆盖其他程序设置的承诺。

## 草稿、导入导出与退出

浏览器自动保留草稿。重新打开后，若草稿与服务器方案不同，显示 **已恢复未保存草稿**，不会静默覆盖。**恢复服务器方案** 是明确操作，可用 Ctrl + Z 撤销本次替换。

方案 JSON 可导入、导出；导出使用当前草稿，无需先保存。认证、订阅和节点密钥不属于方案。**导出脱敏诊断** 提供后端脱敏的状态与历史用于排查。

关闭网页后，中继和后台仍运行。右上角 **退出后台** 会请求恢复系统接入、停止本地入口并退出服务；发生恢复冲突时按错误提示处理。它不会退出 v2rayN、UU、Codex 或游戏客户端。
