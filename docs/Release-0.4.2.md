# 0.4.2 · 把高级分流图改成具体网站与连接方式

高级分流图原来只写“域名规则 1”，没有说明匹配哪些网站；“设计”“入口运行”等提示也容易与软件已经使用代理混淆。本版直接展示网站、去向和分开的执行状态。

- 卡片改为“这些网站 → 普通网络/代理”和“其他网站 → 连接方式”，按实际判断顺序先列网站例外，再列默认连接方式。
- 展示具体网站；网站本身与 `*.` 子域名同时存在时，合并解释为“网站及其子域名”，不修改原匹配规则。只含 `*.` 时明确不含网站本身；`*` 明确表示所有网站。
- 点击卡片中的网站或对应连线可定位右侧设置。右侧用完整句子解释匹配范围和去向，提供填写示例和判断顺序。
- “规则已保存”“分流入口是否运行”“软件实际使用待验证”分别展示。运行中修改图显示“改动尚未应用”；失联时不继续宣称当前规则已加载。
- 草稿虚线与已加载规则的实线分开；代理/普通网络节点采用易读名称，普通网络仍遵循系统路由。入口已启动时可直接前往应用连接设置目标软件。
- 调整节点宽度及按实际尺寸适应画布，保留原软件清单、连接配置、分流内容及网络设置。
