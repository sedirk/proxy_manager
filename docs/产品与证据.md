# 代理接线台

把本机的应用、规则与出口画成可解释的连接图。调音台提供通道与状态，节点软件提供连接与属性，应用通道提供可复制的独立代理入口。

历史证据不会被导入为当前机器检测结果。Xray-only 是保留的实现路径，不要求替换现有核心。

## 工作方式

1. 检测：读取系统代理/PAC、WinHTTP、环境变量、监听端口、进程归属、网络接口/路由/DNS/hosts。
2. 接线：每个通道的默认出口与有序域名规则可调整，预览匹配结果。
3. 运行：在环回地址启动本工具的 HTTP/CONNECT/SOCKS5 TCP 入口；仅处理实际送到这些入口的连接，不做 HTTPS 解密。
4. 接入：应用自身支持代理时填入专属端口。系统代理接入需明确应用并可回退；忽略这些设置的应用仍需其支持的独立接入方式。
5. 验证：记录 DNS、连接、TLS/HTTP 和中继事件。未知状态不会被涂成通过。

## 不做隐式动作

不重启 Codex/代理核心，不改 TUN 或默认路由，不导入节点密钥，不自动更换订阅；不强行给任意进程注入网络钩子。普通 TCP 直连仍可能经过 TUN。SOCKS UDP、QUIC 和真实 RustDesk 会话不因 TCP 检查通过就被认定成功。
