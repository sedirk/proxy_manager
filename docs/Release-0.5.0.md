# FlowDesk 0.5.0

Hermes 安装器和桌面窗口能联网，不代表独立模型后台采用同一代理。本版把后台检查、应用预览和桌面快捷方式加入应用连接画布，供同类问题反复使用。

- **检查此软件**：按需核对所选进程的代理白名单，区分设置已保存、后台就绪、代理环境一致和实际业务未验证。
- **Hermes 应用并打开**：自动识别 Windows 原生 checkout 安装，区分 Setup、CLI 和桌面主程序；先核对数据目录、进程创建时间和后台命令。旧窗口环境不一致时先要求正常退出，避免它抢先拉起旧环境后台。后台重启有独立预览，使用官方非强制生命周期命令。
- **创建桌面快捷方式**：复用最新保存的设置和同一检查流程；不用手输 `-Launch`。中文/空格路径、同名软件与重复创建均有覆盖。快捷方式依赖 FlowDesk 安装位置和本机数据，跨电脑需重新选择路径与入口。
- **本机与私网 IP 绕过**：Hermes HTTP 模式保留环回和私网 IP 直连。局域网主机名、各 profile 私有覆盖、实际订阅授权和模型回复不据此宣称已验证。

系统代理、持久环境变量、TUN、其他应用不因保存、检查或创建快捷方式而改变。普通应用不强制重启；Hermes 后台操作在用户确认后执行。自定义外置 home、不支持的后台格式、权限不足或活动状态不可信时明确停止操作。

验证包括 Python 行为测试、界面事件固定样例、真实 Windows 自建进程的白名单读取、临时目录原生快捷方式、安装版 Hermes HTTP 客户端对本地代理样例的同步/异步请求和私网绕过选择，以及打包 EXE 的资源与 API 验收。测试不启停用户 Hermes、不切 TUN、不调用真实订阅模型。完整生产模型回复和浏览器视觉验收不包含在这些结果中。

211 项 Python 测试、20 项应用连接检查、8 项高级分流检查与 11 项手动清单检查通过。独立 EXE 在中文/空格路径通过资源完整性、检查与启动预览 API、持久化、中继、正常退出验收。本机升级后核对保存方案、软件清单和连接设置保持不变，WinINet、WinHTTP、持久代理环境与受保护进程保持不变。并发外部进程启动使用独立锁保护打包版 DLL 搜索目录。
