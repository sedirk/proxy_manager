# 流向 · 本机代理接线台

把应用通道、域名规则和出口画成接线图，解释本机代理设置，并为显式接入的请求提供本地 HTTP / CONNECT / SOCKS5 TCP 中继。界面和后端都在本机运行，Python 标准库实现，无 npm 依赖。

## 打开工作台

**直接使用：** 在 [GitHub Releases](https://github.com/sedirk/proxy_manager/releases/latest) 下载 Windows x64 的 `.exe`，双击即可打开本机浏览器界面，**不需要安装 Python**。程序内置界面和运行环境，无需管理员权限。配置保存在 `%LOCALAPPDATA%\FlowDesk\.local`，替换新版 exe 时保留。

**从源码运行：** Windows 安装 Python 3.11 或更新版本后，双击 **启动代理接线台.cmd**。默认复用上次页面端口，端口被其他程序占用时才重新分配。重复打开会复用同一服务。

也可在项目目录运行：

```powershell
python run.py
```

首次检测读取系统代理、进程、监听端口、接口、路由、hosts 和 DNS 等线索。启动工作台不会自动接管应用或修改现有系统代理、TUN、路由、Codex、v2rayN 或 UU 设置。

## 日常使用

1. 点击 **自动检测**，在 **分层证据** 查看本机观察值、发现的问题和上次检测后的变化。
2. 选择应用通道，点击其输出圆点，再点出口的输入圆点。右侧可调整默认出口、有序域名规则和本地入口端口。
3. 点击 **预览影响**，核对后 **只启动本地入口**。在 **运行入口** 复制实际代理 URL，再显式配置支持代理的应用。
4. 在通道属性中探测实际运行入口，并结合活动记录与真实应用会话判断结果。新 Steam CDN 可从事件添加为直连规则；草稿修改需停止、重新预览并启动后才成为运行配置。

**设计接线、本机观察、入口监听、真实应用验证分别展示。** 画一条线不会给不支持代理的任意进程注入网络控制。Codex 是保留当前连接的保护节点。

高级 **系统接入** 会另行预览当前用户 WinINet 变更；它影响所有采用该设置的应用，包含域名规则和解析映射。后端允许、用户确认范围后才应用，60 秒内未确认会尝试恢复。检测到第三方改动时保留冲突信息，不强行覆盖。

关闭网页不会退出后台。使用右上角 **退出后台** 请求停止中继并恢复本工具的系统接入；如存在恢复冲突，处理提示后再退出。

## 当前边界

- 直连按系统路由建立 TCP 连接，仍可能经过 TUN；指定接口也不证明真实应用或 UDP 已绕过 TUN。
- 本中继不做 HTTPS 解密，不支持 SOCKS UDP、QUIC 或需要认证的上游代理。
- HTTP 200、TLS 成功或 WebSocket 升级握手只证明对应探测层，不证明完整下载、长连接稳定或 RustDesk 远程会话。
- UU 作为独立加速层观察。私有监听口不会作为 HTTP 出口；截图中的选项、驱动重定向和游戏会话需手动核对。
- DNS 映射只作用于经过本中继的精确域名，保留原 HTTP Host / TLS 域名，不修改系统 hosts。
- WoWS 更新前仍需在资源切换器中隔离共享文件；接线台不负责游戏文件管理。

源码版方案保存在项目的 `.local`，exe 版保存在 `%LOCALAPPDATA%\FlowDesk\.local`；浏览器保留未保存草稿。两版数据独立，可通过界面导出/导入方案迁移。导出诊断由后端脱敏。导入、保存、自动检测均不会自动启动网络入口。
